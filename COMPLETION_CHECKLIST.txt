🚀 QUICK START GUIDE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Start Services
   • Start WAMP/LAMP
   • Ensure Apache is running

Step 2: Create GitHub Token
   • Go to https://github.com/settings/tokens
   • Create new token (classic)
   • Select scopes: repo, public_repo
   • Copy token immediately

Step 3: Access Application
   • Visit http://localhost/projects/repo-pusher/

Step 4: Configure Settings
   • Click "Settings" in sidebar
   • Enter GitHub username
   • Paste Personal Access Token
   • Verify projects folder path
   • Click "Test Connection"
   • Click "Save Settings"

Step 5: Start Backing Up
   • Go to Dashboard
   • Click "Scan Projects"
   • Click "Backup All" or "Backup" on individual projects
   • Watch the magic happen!

Step 6: Verify
   • Check GitHub for new private repos
   • View logs in logs/ folder
   • Check operation status
